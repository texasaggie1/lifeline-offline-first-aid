# Hermes Profile Exports

Hermes Desktop can export an actual profile via Command-K > Export profile or from the profile's context menu. Keep this archive OUT of Git because it can include sessions and memories. `.gitignore` excludes `.tar.gz` and `.zip` in this directory. Save a copy on encrypted external media, and test import on a disposable profile. Source: https://hermes-agent.nousresearch.com/docs/reference/profile-commands
